6. WhatsApp — No API Required

✓ Connected method: your normal WhatsApp app
This version does not use WhatsApp Business API. It opens each dealer's WhatsApp chat with your message already filled in.

How sending works:

  1. Select your dealers.
  2. Tap Send with WhatsApp Now.
  3. Tap Share Price List to WhatsApp.
  4. Choose WhatsApp, select the dealer, then tap Send. If the file cannot be shared, use Open WhatsApp and attach it manually.
  5. Return here and tap Mark Current as Sent to continue to the next dealer.
Important: No API is used. The iPhone share sheet can pass the selected price-list file to WhatsApp, but WhatsApp still requires you to choose the recipient and tap Send. Your existing normal WhatsApp number can remain unchanged.
